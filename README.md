# Agent Skill Collection

可复用的全局 Agent 技能集合。安装前阅读每个技能的 `SKILL.md`，并按自己的环境配置路径、服务和账号。仓库不包含用户凭据或私有数据。

## 本仓库技能

| 技能 | 用途 |
| --- | --- |
| [manage-taskboard](skills/manage-taskboard/SKILL.md) | 管理任务板 |
| [jingyan](skills/jingyan/SKILL.md) | 跨项目经验复用 |
| [knowledge-base-sync](skills/knowledge-base-sync/SKILL.md) | 同步自有知识库；先配置私有远端与路径 |

## 其他常驻技能的原仓库

这些技能由原仓库维护，本合集不复制其代码：

- [admin-backend-builder](https://github.com/dk1275/zuo-ge-hou-tai-skill)
- [gpt-image-2-style-library](https://github.com/freestylefly/awesome-gpt-image-2)

`officecli` 和 `frontend-design` 的再发布条件尚未核实，因此暂不复制。

## 安全

不要提交密钥、令牌、个人路径、私有仓库地址或运行生成的数据。示例中的占位符须替换为自己的配置。
